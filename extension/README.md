# DevBox

Кнопки поверх команды `devbox`.

- **Агенты** — дерево репозиториев скоупа и их ролей (`.claude/roles/<роль>.json`), собранное с
  диска. Клик открывает терминал с именем «репозиторий · роль» и цветом репозитория и запускает в
  нём агента; запущенный отмечен, повторный клик показывает уже открытый терминал.
- **Новый скоуп** — в пустом скоупе панель предлагает создать стартовые конфиги.

Расширение едет в образе девбокса и ставится само.
